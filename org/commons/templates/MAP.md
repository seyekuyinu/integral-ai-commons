# Commons Map

> The only file agents load at session start. It says where answers live, not
> what they are. Find the row that matches the question, open that one file,
> and load nothing else. Keep each row to one line so this file stays small.

## Where to look

| If the question is about… | Open |
|---|---|
| Whether something is already decided, and the one-line answer | `commons/INDEX.md` |
| Stack, key files, gotchas, glossary, current priorities | `commons/context.md` |
| Why a technical choice was made (`ENG-NNN`) | `commons/engineering.md` |
| Why a product, scope, or strategy choice was made (`PRD-NNN`) | `commons/product.md` |
| What is waiting for a human decision | `commons/proposals/` |
| How this team works: readiness, done, review, handoffs | The convention listed below |
